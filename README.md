# 📊 Анализатор данных (Data Analyzer)

Десктопное приложение на Python для ефективной обработки табличных данных. Проект демонстрирует навыки работы с 데이터, фильтрами, статистикой 및 экспортом в Excel.

## 📸 Скриншоты


## 🚀 Функционал
- **Импорт:** Читает CSV и Excel файлы (конвейерная адаптация к различным разделителям).
- **Анализ:** Показывает статистику по числовым колонкам (Среднее, Медиана, Мин, Макс, и причем частные).
- **Фильтр:** Позволяет зафильтровать данные по снятому порогу.
- **Экспорт:** Выгружает данные в Excel (формат XLSX).
- **Трехсторонняя работа:** Данные выставляются в интерфейсе, сохранены в Базу и выгружаются в Excel.

## 🛠️ Технологии
- Python 3.10+
- Tkinter (GUI)
- Pandas (Функции и анализ)
- Numpy (числовые секции)
